RULES - follow these exactly
1. DO NOT UNINSTALL ANYTHING. Use only `pm disable-user --user 0`, so every
   change can be undone with `pm enable <package>`. `pm uninstall` is forbidden.
2. Do not suggest or attempt rooting, unlocking the bootloader, or flashing a
   custom ROM. That factory-resets the TV, and if the Widevine certificate
   drops from L1 to L3 Netflix falls back to SD. There is nothing to gain.
3. BACK UP AND MEASURE FIRST. Before changing anything, save these to a
   `tv-debloat` folder: `pm list packages -f`, `pm list packages -d`,
   `getprop`, `settings list global`, `settings list secure`,
   `settings list system` and `dumpsys meminfo`. Start a restore script
   (`restore.sh`, or `restore.ps1` on Windows) right away and add every
   package to it the moment you disable it. Repeat the memory measurement at
   the end and give me a before/after table.
4. CHECK YOUR OWN WORK ON THE TV. After every batch, press keys with
   `adb shell input keyevent` (Home, the D-pad, Back, Inputs/Source), pull a
   screenshot with `adb exec-out screencap -p > shot.png` and look at it:
   does the home screen come up, does the Inputs menu open, can you switch
   to HDMI, do Netflix and YouTube still launch? Fix what you see before
   moving on. If the screenshot comes out blank while Live TV or HDMI is on
   screen, press Home first. Ask me only about what a screenshot cannot
   show: sound, the remote's own buttons, the on-screen keyboard.
5. SMALL BATCHES, ONE COMMAND AT A TIME. Disable at most 10 packages per
   batch. Run each `pm` command in its own shell call: chained commands can
   silently stop after the first one. If something breaks, re-enable the
   last batch first, then narrow it down one package at a time.
6. NEVER DISABLE WHAT THE TV NEEDS TO WORK, whatever the brand:
   - the TV app and the input services that play HDMI and the antenna/tuner
   - the Inputs/Source menu (the brand's "quick panel")
   - the remote control and Bluetooth pairing services
   - the on-screen keyboard (*.inputmethod.*)
   - Play Store and Play Services: com.android.vending,
     com.google.android.gms, com.google.android.gsf
   - com.android.location.fused: disabling it sends the TV into a boot loop
   - the current home screen, until a new one is installed and set as default
   Package names often do not say what a package does. Before disabling one
   you are unsure of, look at its activities and services with
   `dumpsys package <name>`. If it is still unclear, ask me.
   Known traps on TCL, for example:
      com.tcl.suspension          -> the Inputs/Source menu on the remote.
                                     The name looks like junk but disabling it
                                     means you can no longer switch to HDMI.
      com.tcl.ttvs                -> system updates (Network / USB). The name
                                     suggests a text-to-speech service, but
                                     disabling it makes every option in the
                                     system update menu silently stop working.
      com.tcl.tv, com.tcl.tvinput -> HDMI / antenna input services
      com.tcl.providers.config,
      com.tcl.initsetup           -> disabling either drops the Wi-Fi
      com.google.android.tv.remote.service,
      com.tcl.tcl_bt_rcu_service,
      com.tcl.autopair            -> the remote control
7. ASK BEFORE ANYTHING THAT DEPENDS ON ME. Streaming apps, the voice
   assistant, Chromecast, screen mirroring and the system update service:
   show me a checklist and disable only what I do not tick.
8. KEEP A RECORD. Write every package you disable to `disabled.txt` in the
   `tv-debloat` folder. Keep a `DEBLOAT-LOG.md` in the same folder describing
   what you did, why, and the exact command to undo each change.
